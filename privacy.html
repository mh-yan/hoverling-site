在你的 Mac 上处理的内容

  • 截图：只截取指针附近或你框选的区域，在本机内存中识别文字，不保存到磁盘，也不上传。
  • Apple 翻译与词典：由 macOS 处理，适用 Apple 的隐私政策。
  • 本地数据：生词本、最近取词、设置、授权码和诊断记录（只有阶段、耗时和错误码，不含文字或截图）保存在 ~/Library/Application Support/HoverLing/；你自己的 API 密钥保存在 macOS 钥匙串，不同步到 iCloud。删除该文件夹和钥匙串中的「local.hoverling」条目即可清除。

使用内置「悬译 AI」时

识别出的文字和附近最多约 2400 字的上下文，会经我们的服务器转发给 DeepSeek 完成翻译，结果直接传回你的 Mac。

  • 我们的服务器不保存、不记录任何翻译文字。
  • 为了计算额度和设备数，服务器保存：本机机器码（硬件标识经单向哈希后的短编码，无法还原硬件信息）、授权 ID（如已激活）、每日/每月用量计数、每个授权码使用过的机器码、以及按天计数的 IP 地址加盐哈希（不保存原始 IP）。
  • 翻译文字由 DeepSeek 处理，适用 DeepSeek 的隐私政策。
  • 不想经过我们的服务器：改用 Apple 翻译，或在付费方案中接入你自己的 API。

使用你自己的 API 时（付费方案）

文字用你自己的 API 密钥直接发送给你选择的服务商（例如 DeepSeek、阿里云百炼、Anthropic、OpenAI），不经过我们的服务器，处理方式由该服务商的隐私政策决定。选择「Ollama（本机模型）」时，请求只发往你自己的电脑或局域网。

授权码与机器码

授权码在本机验证；使用悬译 AI 时，授权码会随请求发送给我们的服务器以确认方案。「本机机器码」只有在使用悬译 AI 或你主动发给我们时才会离开你的 Mac。
